Оригиналыг https://fonts.bolorsoft.com/web/ доороос TTF хэлбэрээр татсан:
  cmdashitseden.ttf · MongolianScript.ttf · MongolianSystem.ttf
Эндхийн .woff2 файлууд нь тэдгээрийн ЗӨВХӨН савлагааг сольсон хувилбар —
глиф, cmap, GSUB/GPOS/GDEF бүрэн хэвээр, subset хийгээгүй (нийт 757 KB ->
242 KB). Гуужуулаагүй шалтгаан нь эдгээр фонт 0xE2xx муж дахь PUA кодыг
өргөн ашигладаг: Bolorsoft-ын хөрвүүлэгчийн гаргац PUA-гаар ирдэг тул
subset хийвэл чимээгүйхэн эвдэрнэ.

Дахин үүсгэх:
    pip install fonttools brotli
    python -c "from fontTools.ttLib import TTFont; f=TTFont('X.ttf'); f.flavor='woff2'; f.save('X.woff2')"
