# Facebook бот — сэтгэгдлийг монгол бичгээр буцаах

Хуудасны пост дор хэн нэгэн сэтгэгдэл бичихэд ботын хийх зүйл:

1. бичвэрийг уншиж, кирилл үгсийг **монгол бичигт хөрвүүлнэ**
   (сайтын хөрвүүлэгчтэй яг ижил дүрэм, ижил толь);
2. хөрвүүлснийг **1080×1080 зураг** болгож бичнэ;
3. тэр зургаар **сэтгэгдэлд нь хариулна**.

Messenger-ээр ирсэн чат ч мөн адил — зөвхөн хариу нь сэтгэгдэл биш, мессеж
болж очно.

## Яагаад бичвэрээр биш зургаар хариулдаг вэ

Монгол бичгийн юникод муж (U+1800–U+18AF) нь ихэнх утсанд фонтгүй. Сэтгэгдэлд
бичвэрээр буулгавал хүлээн авагчийн дэлгэц дээр дөрвөлжин хайрцаг эгнэнэ.
Зураг нь хаана ч ижил харагдана — тиймээс хариу нь зураг.

## Тохируулах

### 1. Орчны хувьсагч

`.env.local` дотор дөрвийг нь бөглөнө ([.env.example](../../.env.example)-д
тайлбартай):

```
FB_PAGE_ID=<хуудасны тоон ID>
FB_PAGE_ACCESS_TOKEN=<хуудасны урт хугацааны токен>
FB_APP_SECRET=<апп-ын Secret>
FB_VERIFY_TOKEN=<өөрөө зохиосон нууц үг>
```

Дөрвөөс нэг нь ч дутвал бот бүхэлдээ унтарч, вэбхүүк `503` буцаана. Энэ нь
санаатай: `FB_APP_SECRET`-гүйгээр гарын үсэг шалгах боломжгүй бөгөөд шалгалтгүй
вэбхүүк нь хэн ч дуудаж болох нээлттэй хаалга болно.

### 2. Meta апп

[developers.facebook.com](https://developers.facebook.com) дээр **Business**
төрлийн апп үүсгээд:

- **Messenger** ба **Webhooks** бүтээгдэхүүнийг нэмнэ;
- хуудсаа холбож, дараах эрхийг авна:
  `pages_manage_engagement` (сэтгэгдэлд хариулах),
  `pages_read_engagement` (сэтгэгдлийг унших),
  `pages_messaging` (Messenger-ээр хариулах);
- **Хуудасны токеныг урт хугацаатай болгоно** — эс бөгөөс 60 хоногийн дараа
  бот чимээгүй унтарч, лог дээр `Graph 190` алдаа гарна.

### 3. Вэбхүүк бүртгэх

- **Callback URL**: `https://<домэйн>/api/facebook/webhook`
- **Verify Token**: `FB_VERIFY_TOKEN`-той яг ижил
- **Subscribe to fields**: `feed` (сэтгэгдэл) ба `messages` (Messenger)

Бүртгэх даруунд Facebook нэг удаа `GET` илгээж `hub.challenge`-г буцаахыг
шаардана — маршрут үүнийг өөрөө хийнэ. Амжилтгүй бол дараах хоёрыг шалга:
хаяг гаднаас хүрэх боломжтой юу, `FB_VERIFY_TOKEN` таарч байна уу.

Дараа нь хуудсаа апп руу **subscribe** хийхээ бүү мартаарай:

```bash
curl -X POST "https://graph.facebook.com/v26.0/<PAGE_ID>/subscribed_apps" \
  -d "subscribed_fields=feed,messages" \
  -d "access_token=<PAGE_ACCESS_TOKEN>"
```

### 4. Шалгах

Facebook-гүйгээр зураг нь ямар гарахыг харах:

```
https://<домэйн>/api/bichig?text=сайн байна уу
```

Бот болон энэ хаяг **нэг функц** дууддаг тул энд харсан зураг чинь Facebook
дээр очих зураг мөн.

## Зан үйл

| Нөхцөл | Хариу |
| --- | --- |
| Кирилл үгтэй сэтгэгдэл | Зурган хариу + богино тайлбар |
| Кирилл үггүй (зөвхөн эможи, латин) | Сэтгэгдэлд юу ч бичихгүй |
| Кирилл үггүй Messenger чат | «Кирилл үгээ бичээрэй» гэсэн богино мессеж |
| Хуудас өөрөө бичсэн | Алгасна — эс бөгөөс бот өөртэйгөө ярина |
| 220 тэмдэгтээс урт | Тасалж, «…» тавина |
| Толинд байхгүй үг | Хариунд «дуудлагаар бичив — шалгаарай» гэж нэмнэ |

Сүүлийн мөр нь чухал: хөрвүүлэгч нь толинд байхгүй үгийг **дуудлагаар таадаг**
бөгөөд тэр таамаг буруу байж болно. Үүнийг нуувал хэрэглэгч буруу бичлэгийг
зөв гэж итгэнэ.

## Хязгаар ба анхаарах зүйл

**Давхардлын хамгаалалт нь санах ойд сууна.** Facebook хариу 200 аваагүй гэж
үзвэл вэбхүүкийг дахин илгээдэг тул боловсруулсан сэтгэгдлийн ID-г санадаг.
Энэ нь процессын дотор — PM2 сэргээхэд цэвэрлэгдэнэ (тэр үед хамгийн ихдээ нэг
сэтгэгдэлд давхар хариулж магадгүй). Апп-ыг **олон хувиар** ажиллуулах болбол
үүнийг DB рүү зөөх ёстой — [facebookBot.ts](../../src/lib/site/facebookBot.ts) дотор
тэмдэглэсэн.

**Зурагдалт нь хариунаас хойш явна.** Хөрвүүлэлт, зурагдалт, Graph руу илгээх
нь хэдэн секунд авдаг. Facebook удаан хүлээвэл вэбхүүкийг дахин илгээж, эцэст
нь унтраадаг тул ажлыг `after()` дотор, хариу буцсаны дараа гүйцэтгэнэ.
Тиймээс **алдаа нь HTTP статусаар харагдахгүй** — зөвхөн лог дээр
(`[facebook]` угтвартай).

**Сервер дээр монгол фонт хэрэгтэй.** Зураг нь `sharp` → librsvg → Pango →
HarfBuzz гинжээр зурагддаг бөгөөд фонтыг fontconfig-оор олдог. fontconfig нь
WOFF2 уншдаггүй тул `public/fonts/mongol/` дотор ижил фонтын **TTF** хувилбар
зэрэг хэвтэнэ. Дэлгэрэнгүйг [font.md](./font.md)-ээс.

**`/api/bichig` нь нээлттэй бөгөөд тооцоолол их шаарддаг.** Нэг зураг зурахад
хэдэн зуун миллисекунд авна. Хариуг нь удаан кэшлүүлдэг ч урд нь CDN байхгүй
бол энэ хаягийг Nginx дээр хязгаарлах нь зүйтэй.
