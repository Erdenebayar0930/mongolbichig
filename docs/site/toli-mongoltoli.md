# mongoltoli.mn-ээс толь хураах

«Монгол хэлний их тайлбар толь» (<https://mongoltoli.mn>)-оос кирилл → монгол
бичгийн хосыг татаж, Postgres-ийн `site_toli` хүснэгтэд хийнэ.

## Яагаад Postgres, багц биш вэ

`src/lib/mongolLexicon.ts` нь `mongolText.ts` → `TextConverter.tsx`
(`"use client"`) гинжээр орох тул **бүхэлдээ хөтөч рүү явдаг**. Одоогийн 215 үг
нь ~8 KB. Толийн бүтэн сан нь хэдэн арван мянган бичлэгтэй — багцад хийвэл
хөрвүүлэгчийн хуудсыг ачаалахын аргагүй болно.

Тиймээс хоёр давхарга:

| Давхарга | Хаана | Хэн |
| --- | --- | --- |
| Багшаар нягталсан цөм үгс | `mongolLexicon.ts`, багцад | шууд, сүлжээгүй |
| Бүтэн толь | `site_toli`, Postgres | `/api/toli` багц хайлт |

## Урсгал

```bash
npm run toli:index      # толгой үгсийн жагсаалт  (~10-20 мин)
npm run toli:fetch      # монгол бичгийн хэлбэр   (УРТ — доор үз)
npm run db:push         # site_toli хүснэгт үүсгэх (нэг удаа)
npm run toli:import     # JSONL → Postgres
```

### 1. `index`

`letter.php` → 308 хос үсгийн бүлэг → `browsepage.php?zuil_useg=XX&page=N`.
Хуудас тутамд 98 холбоос, тус бүр нь `(ug_id, кирилл)`.

Гаралт: `scripts/data/mongoltoli-index.jsonl`

> ⚠ Хуудаслалтыг зогсоох нөхцөл нь **хуудасны дүүргэлт** (`< 90 холбоос`),
> «шинэ үг алга» БИШ. Эхний хувилбар сүүлийнхээр зогсоодог байсан тул дахин
> ажиллуулахад бүх хуудас кэшнээс ирж, «шинэ алга» болоод шууд тасардаг байв —
> ингэж «ба» бүлэг 3 хуудсан дээр зогсож, 4-8-р хуудсан дахь олон зуун үг
> индекст ороогүй үлдсэн. Энэ дүрмийг бүү өөрчил.

### 2. `detail`

Монгол бичгийн хэлбэр нь зөвхөн дэлгэрэнгүй хуудасны нуугдмал талбарт байна:

```html
<input readonly id="uigarjin_tolgoi_useg_input" value="ᠠᠪᠤ " />
```

Индекс хуудас үүнийг **өгдөггүй** тул үг тутамд нэг хүсэлт хэрэгтэй — товчлол
байхгүй. 0.4 сек завсарлагатай **үг тутамд ~0.4 сек**.

Гаралт: `scripts/data/mongoltoli-words.jsonl`

Үндсэн байдлаар олон үгт хэлц, зүйр цэцэн үгийг алгасна (`--all-entries`-ээр
оруулна) — язгуурын толинд хэрэггүй.

### 3. `import`

`ug_id`-аар upsert. Кирилл үгийг **жижиг үсэг** болгож нормчилно — `/api/toli`
мөн адил нормчилдог тул хоёр тал таарна. Хураалт тасарч дахин үргэлжилсэн ч
импортыг дахин дуудахад давхардал үүсэхгүй.

## Хөрвүүлэгчтэй хэрхэн холбогдсон

`convertText` нь **синхрон хэвээр** — сүлжээ рүү async болгож задлаагүй.
Оронд нь хоёр шаттай:

1. `convertText(input)` урьдын адил ажиллаж, олдоогүй үгсээ `unknown`-оор буцаана.
2. `TextConverter` тэдгээрийг `/api/toli`-д багцаар илгээж, хариуг
   `rememberToli()`-оор модулийн кэшэд хийгээд дахин тооцоолуулна.

Ингэснээр хөрвүүлэлтийн логик цэвэр, туршихад хялбар хэвээр үлдэж, сүлжээний
ажил зөвхөн бүрэлдэхүүн дотор байрлана.

> ⚠ **Төгсгөлгүй давталтын урхи.** Сервер үгийг олохгүй бол тэр үг `unknown`-д
> үлдэнэ → эффект дахин асна → дахин асууна. Тиймээс `asked` ref нь асуусан
> БҮХ үгийг тэмдэглэдэг — олдоогүйг нь ч оруулаад. Энэ шалгалтыг бүү устга.

Сүлжээ тасарвал `fetch` чимээгүй бууж, багцад суусан толиор ажилласаар байна.

### Итгэлцлийн дөрөв дэх түвшин

`Certainty` дээр `"toli"` нэмэгдсэн. Хөрвүүлэгчийн гол зарчим нь итгэлцлийг
нуухгүй байх учир Их тайлбар толиос ирсэн үгийг «Нягталсан» гэж дүрсэлж
болохгүй: эх сурвалж нь эрдэм шинжилгээнийх ч, **нөхцөл залгалт нь дүрмээр
хийгддэг** тул эцсийн үр дүн шалгагдаагүй хэвээр. Тиймээс хамгийн нимгэн
цэгтэй зураастай — «шалгасан ч эцсийн биш».

Дараалал нь: `mongolLexicon` → нэрийн `STEMS` → **толь**. Гар хийцийн хоёр
толь нь энэ сайтын хэрэгцээнд тааруулж нягталсан тул дарагдах ёсгүй.

## Эелдэг байх

Сервер нь **Apache 2.2** — хуучин, жижиг. `robots.txt` байхгүй (404) боловч
энэ нь зөвшөөрөл биш. Тиймээс скрипт:

- нэг урсгал, зэрэгцээ хүсэлтгүй;
- хүсэлт хооронд 0.4 сек;
- түүхий HTML-ийг `.cache/mongoltoli/` дор gzip-лэн хадгална — **дахин
  ажиллуулахад сүлжээнд огт хүрэхгүй**;
- тасарвал үргэлжилнэ (JSONL нь нэмэгддэг, аль хэдийн татсаныг алгасна).

Кэшийг репод бүү оруул (`.gitignore`-т `.cache/`).

## Эрхийн асуудал

Эх сурвалж нь ШУА-ийн Хэл зохиолын хүрээлэнгийн **эрдэм шинжилгээний бүтээл**.
Хувийн болон дотоод хэрэглээ нэг хэрэг, толийн санг өөрийн бүтээгдэхүүн болгон
**нийтэд тараах** нь өөр хэрэг. Сайтад тавихаасаа өмнө ашиглах эрхээ
тодруулах хэрэгтэй — `site_toli` дотор `ug_id` хадгалагдаж байгаа нь эх
сурвалж руу буцааж холбох, эшлэл өгөх боломжийг үлдээж байгаа юм.

## Мэдэгдэж буй зүйлс

- `ug_id` нь **тасалданги** ба 10 сая хүртэл тархсан (олон нийтийн нэмсэн үг
  өөр мужид сууна) — тиймээс `1..N` гэж дараалуулан тойрч БОЛОХГҮЙ, зөвхөн
  индексээс гарсан жагсаалтаар яв.
- Нэг кирилл үг олон `ug_id`-тай байж болно (омоним). `/api/toli` хамгийн бага
  дугаартайг нь сонгодог — эх толинд эхэлж бүртгэгдсэн нь ерөнхийдөө үндсэн утга.
- `letter.php` дээр нэг алдаа бий: **АМ** бүлэг нь `zuil_useg=ал` руу заасан
  байдаг. Тиймээс «ам»-аар эхэлсэн зарим үг индекст дутуу орох магадлалтай.
