# Монгол бичгийн фонт

## Одоо юу ашиглаж байна

Сайт **Bolorsoft**-ын гурван монгол бичгийн фонтыг өөрөө хостолж
([public/fonts/mongol/](../../public/fonts/mongol/)), тэдгээрийг
[globals.css](../../src/app/(site)/globals.css) дотор `@font-face`-ээр зарлана.

| Фонт | CSS нэр | Хэмжээ | Онцлог |
| --- | --- | --- | --- |
| **Classical Mongolian Dashitseden** | `"Classical Mongolian Dashitseden"` | 71 KB | Сонгодог, зузаан нимгэний хэлбэлзэлтэй. **Үндсэн** |
| **MongolianScript** | `"MongolianScript"` | 113 KB | Хамгийн бүдүүн, өндөр ялгаралтай. Кирилл ч агуулна |
| **Mongolian System** | `"Mongolian System"` | 58 KB | Жигд зузаантай, техникийн. Кирилл агуулна |

`--font-mongol` хувьсагч нь Dashitseden-ээр эхэлж, ард нь **Noto Sans
Mongolian** (`next/font/google`-оор ирсээр байгаа, `--font-mongol-script`) ба
системийн **Mongolian Baiti** fallback-аар үлдэнэ.

Нүүр солих: `.mongol`-ын хажууд `.mongol-dashitseden` / `.mongol-script` /
`.mongol-system` засварлагчийн аль нэгийг тавина — оронд нь биш, хажууд нь.

```html
<span class="mongol mongol-script">ᠨᠡᠷᠡ</span>
```

### Лиценз

Фонтын `name` хүснэгтийн 13-р бичлэгт үгчлэн:

> *"Bolorsoft free font. This font may be downloaded, distributed and used
> free of charge for both personal and commercial use. Any other use is
> prohibited."*

Өөрөөр хэлбэл татах, **түгээх**, худалдааны хэрэглээ зөвшөөрөгдсөн тул өөрөө
хостлох эрхтэй. Харин фонтыг **засварлах, дахин нэрлэх, эсвэл фонтыг өөрийг нь
бүтээгдэхүүн болгон зарах** нь "any other use" дор орж, хориотой.
Дэлгэрэнгүйг [LICENSE.txt](../public/fonts/mongol/LICENSE.txt)-ээс үз.

### ⚠ Сервер талд TTF хос хэрэгтэй

`public/fonts/mongol/` дотор WOFF2-ын хажууд **TTF** хоёр файл хэвтэнэ:

| Файл | Хэнд |
| --- | --- |
| `cmdashitseden.ttf` | Facebook ботын зурдаг монгол бичиг |
| `MongolianSystem.ttf` | Тэр зураг дээрх кирилл тайлбарын аврах фонт |

Шалтгаан нь: зураг зурагдалт ([mongolPoster.ts](../../src/lib/site/mongolPoster.ts))
нь `sharp` → librsvg → **Pango** гинжээр явдаг бөгөөд Pango фонтыг
**fontconfig**-оор олдог. fontconfig нь **WOFF2 уншдаггүй** — хөтөчид өгдөг
файлууд сервер талд огт харагдахгүй.

`MongolianSystem.ttf` нь кирилл үсэг агуулдаг (Dashitseden агуулдаггүй) тул
системд кирилл фонтгүй нүцгэн серверт ч тайлбар хайрцаг болж хоцрохгүй.

**Фонт солих, нэмэх бүрд TTF-ийг нь мөн адил тавь.** Мартвал вэб дээр юу ч
өөрчлөгдөхгүй, зөвхөн ботын зураг дээр үсэг алга болно — чимээгүй эвдрэл.

WOFF2-оос TTF гаргах (`pip install fonttools brotli`):

```bash
python -c "from fontTools.ttLib import TTFont; f=TTFont('X.woff2'); f.flavor=None; f.save('X.ttf')"
```

### Яагаад subset хийгээгүй вэ

Эдгээр фонт **0xE2xx PUA** мужийг өргөн ашигладаг (Dashitseden 196, Script
454, System 237 кодтой). Bolorsoft-ын хөрвүүлэгчийн гаргац PUA-гаар ирдэг тул
`unicode-range` заах буюу гуужуулах нь бичвэрийг **чимээгүйхэн** эвдэнэ.
Тиймээс зөвхөн TTF → WOFF2 савлагаа сольсон (757 KB → 242 KB, 68% бага).

Дахин үүсгэх:

```bash
pip install fonttools brotli
python -c "from fontTools.ttLib import TTFont; f=TTFont('X.ttf'); f.flavor='woff2'; f.save('X.woff2')"
```

## ⚠ Үндсэн фонтыг солихдоо `/ner`-ийг заавал шалга

`/ner` хуудасны зотон нь фонтын нэрийг нуугдмал элементийн **тооцоолсон
загвараас** уншдаг ([NameCalligraphy.tsx](../../src/components/site/name/NameCalligraphy.tsx)
465-р мөр) — өөрөөр хэлбэл `--font-mongol`-ыг солиход зотон **дуугүй дагаж**
өөрчлөгдөнө.

Асуудал нь: «Бийр» хэв үсгийг бийрийн үзүүрийн өнцгөөр **18 удаа давхарлан**
зурдаг. Аль хэдийн бүдүүн нүүр дээр тэр давхарлалт нэмэгдэнэ. MongolianScript-
ийг үндсэн болгож үзэхэд «Батбаяр» нь татлага нь ялгарахгүй **хар бөөн** болсон.
Dashitseden нимгэн, хэлбэлзэлтэй тул давхарлалт нь эсрэгээрээ уран бичлэгийн
чанарыг гаргаж өгсөн — үндсэн болгосон шалтгаан нь энэ.

Бүдүүн нүүр рүү шилжих шаардлага гарвал `SCRIPTS` доторх `nib` утгыг
0.085-аас 0.03 орчим болгож багасгана.

## Нэрийн уран бичлэг дээрх бийрийн зан үйл

| Хэв | Юу хийдэг |
| --- | --- |
| **Бийр** | Үсгийг бийрийн үзүүрийн өнцгийн дагуу 18 удаа давхарлан зурна. Давхарлах чиглэлд перпендикуляр татлага (баганын нуруу) бүдүүрч, зэрэгцээ нь (шүд, сүүл) нарийн үлдэнэ — ташуу иштэй бийрийн үлдээх мөр. Дээр нь бэх цаасанд шингэсэн зөөлөн хүрээ. |
| **Хуурай бийр** | Дээрхийн дээр татлагын дагуух сунасан цэгүүдээр бэхийг сийрэгжүүлнэ — бэх нь дуусах дөхсөн бийрийн ул мөр. |
| **Хэвлэмэл** | Фонтыг байгаагаар нь, татлагыг л бага зэрэг зузаалж. |

## Өөр фонт нэмэх

1. Лицензийг нь **эхлээд** шалга — фонтын `name` хүснэгтийн 13/14-р бичлэгээс
   (`fontTools`-оор уншина). Ихэнх монгол фонтын лиценз зөвхөн компьютерт
   суулгахыг зөвшөөрдөг бөгөөд вэбээс тараахыг тусад нь худалдан авдаг.
2. WOFF2 болгож `public/fonts/mongol/` дор хийнэ.
3. `globals.css`-ийн `@font-face` блокт нэмнэ.
4. `.mongol-<нэр>` засварлагч нэмнэ. Үндсэн болгох бол `--font-mongol`-ын
   эхэнд тавиад дээрх `/ner` шалгалтыг хий.
